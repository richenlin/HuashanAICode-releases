# HuashanAICode 安装包

这个仓库只发布 HuashanAICode 桌面端安装包，可以直接下载。源码不在这里。

安装包没有代码签名，也没有 Apple 公证。请用 Release 里的 SHA256 核对文件。

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `HuashanAICode-<版本>-win-x64-setup.exe` |
| macOS Apple Silicon | `HuashanAICode-<版本>-mac-arm64.zip` |
| Linux x64 | `HuashanAICode-<版本>-linux-amd64.deb` |
| Linux arm64 | `HuashanAICode-<版本>-linux-arm64.deb` |

下载页：<https://github.com/richenlin/HuashanAICode-releases/releases>
